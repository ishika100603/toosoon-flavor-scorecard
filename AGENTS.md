## Standard operating procedures
- Before completing a task, run "npm run build" and fix any build errors.
- Use only web-safe fonts across the repository (no custom or hosted fonts).

## Screen sizes
- This is a computer-only application.  No need to optimize for mobile.
- Optimize the layout for the following devices:
  - Computer with monitor: 1464 wide by 1300 tall
  - 15-inch MacBook Pro: 1440 wide by 900 tall

## Supabase schema
- The latest database types live in src/types/supabase.ts
- This is generated by running npm run supabase:types
- The user does not want to use a SUPABASE_ROLE_KEY.  All actions should use the logged-in user's JWT key.

## Prompt examples
- The prompt "update /humor-flavor/51", for example, actually means "update /humor-flavor/<id>"
